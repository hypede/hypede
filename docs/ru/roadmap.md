# Дорожная карта

## 1.0 — GNOME в облике Chrome OS (сделано)

- [x] Сеанс HypeDE на чистом GNOME Shell (режим оболочки + systemd-юниты gnome-session)
- [x] Полка: кольцо лаунчера, закреплённые и запущенные приложения, трей с датой и временем
- [x] Лаунчер-«пузырь»: поиск, калькулятор, веб-поиск, недавние файлы, сетка приложений
- [x] Быстрые настройки, календарь и меню открываются вверх; уведомления справа внизу
- [x] Автоскрытие полки, Super → лаунчер, вход сразу на рабочий стол
- [x] Светлая и тёмная тема оболочки, акцент из системы, свои обои
- [x] «Настройки»: интерфейс Chrome OS, встраиваемые модули KDE, разделы на GSettings, поиск
- [x] «Файлы»: GNOME Files + вкладки и панель сведений COSMIC, операции с отменой
- [x] Русский перевод, пакет для Arch/CachyOS
